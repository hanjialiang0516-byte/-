# 经营统计模块接口文档

## 1. 导出经营统计数据

### 接口说明
导出指定时间范围内的酒店经营统计数据为 Excel 文件，支持按房型、订单状态筛选。

### 基本信息
- **接口地址**：`/api/admin/reports/export`
- **请求方式**：`GET`
- **Content-Type**：`application/json`
- **权限要求**：需要管理员权限（`ROLE_ADMIN`）

---

### 请求参数

#### Query 参数（可选）

| 参数名 | 类型 | 必填 | 说明 | 示例值 |
|--------|------|------|------|--------|
| `startDate` | `LocalDate` | 否 | 开始日期（默认最近 30 天） | `2026-03-01` |
| `endDate` | `LocalDate` | 否 | 结束日期（默认今天） | `2026-04-09` |
| `roomTypeId` | `Long` | 否 | 房型 ID 筛选 | `1` |
| `status` | `Integer` | 否 | 订单状态筛选（0-待确认，1-已确认，2-已入住，3-已退房，4-已取消） | `2` |

#### 请求头

| 参数名 | 类型 | 必填 | 说明 | 示例值 |
|--------|------|------|------|--------|
| `Authorization` | `String` | 是 | JWT Token（格式：`Bearer <token>`） | `Bearer eyJhbGci...` |

---

### 请求示例

```http
GET /api/admin/reports/export?startDate=2026-03-01&endDate=2026-04-09&roomTypeId=1&status=2
Authorization: Bearer eyJhbGciOiJIUzI1NiJ9.eyJzdWIiOiJhZG1pbiIsInVzZXJJZCI6MSwicm9sZSI6MX0.xxx
```

---

### 响应说明

#### 成功响应
- **状态码**：`200 OK`
- **Content-Type**：`application/vnd.openxmlformats-officedocument.spreadsheetml.sheet`
- **响应体**：Excel 文件流（自动触发浏览器下载）

#### 响应头
```http
Content-Type: application/vnd.openxmlformats-officedocument.spreadsheetml.sheet
Content-Disposition: attachment;filename*=utf-8''经营统计_2026-04-09.xlsx
```

#### 失败响应

**403 Forbidden（权限不足）**
```json
{
  "code": 403,
  "message": "Forbidden",
  "data": null
}
```

**500 Internal Server Error（服务器错误）**
```json
{
  "code": 500,
  "message": "导出失败：数据库连接异常",
  "data": null
}
```

### Excel 文件内容

导出的 Excel 文件包含以下列：

| 列名 | 字段类型 | 说明 | 示例值 |
|------|----------|------|--------|
| 支付时间 | `LocalDateTime` | 订单支付时间 | `2026-04-09 14:30:00` |
| 订单号 | `String` | 订单编号 | `ORD20260409001` |
| 房间号 | `String` | 房间编号 | `201` |
| 房型 | `String` | 房型名称 | `标准间` |
| 入住人 | `String` | 客人姓名 | `张三` |
| 入住天数 | `Integer` | 入住总天数 | `3` |
| 金额 (元) | `BigDecimal` | 订单总金额 | `598.00` |
| 入住日期 | `LocalDate` | 计划入住日期 | `2026-04-10` |

---

### 业务逻辑说明

1. **默认时间范围**：如果前端未传递 `startDate` 和 `endDate`，系统默认查询最近 30 天的数据。
2. **时间精度处理**：开始时间自动设置为 `00:00:00`，结束时间自动设置为 `23:59:59.999`，确保包含完整日期范围。
3. **联表查询**：通过 `LEFT JOIN` 关联 `booking`、`room`、`room_type` 三张表，一次性获取所有数据。
4. **动态 SQL**：根据传入参数动态拼接 WHERE 条件，未传递的参数不参与筛选。
5. **流式写入**：使用 EasyExcel 直接将数据写入 HTTP 响应流，无需生成临时文件，内存占用低。

---

### 注意事项

1. **Token 格式**：`Authorization` 请求头必须严格按照 `Bearer <空格> <token>` 格式传递。
2. **日期格式**：日期参数必须符合 `yyyy-MM-dd` 格式（如 `2026-04-09`）。
3. **权限校验**：该接口需要管理员角色（`role = 1`），普通用户访问会返回 403。
4. **文件编码**：文件名使用 UTF-8 编码，支持中文显示。
5. **大数据量**：如果查询结果超过 10 万条，建议添加分页或限制时间范围，避免内存溢出。

### 测试建议

#### 使用 Apifox/Postman 测试
1. 在 **Headers** 中添加 `Authorization: Bearer <你的 Token>`
2. 在 **Params** 中添加查询参数（可选）
3. 点击 **"发送并下载"** 按钮
4. 检查下载的 Excel 文件内容是否正确

#### 使用浏览器测试
1. 临时在 `SecurityConfig.java` 中添加 `.requestMatchers("/api/admin/reports/export").permitAll()`
2. 直接在浏览器访问：`http://localhost:8080/api/admin/reports/export?startDate=2026-03-01&endDate=2026-04-09`
3. 浏览器会自动下载 Excel 文件
4. **注意**：测试完成后务必删除临时放行配置！
